## Module 1: Cloud and computing foundations

Cloud definitions, on-premises and cloud models, IaaS, PaaS, SaaS, serverless, control plane, data plane, regions, zones, elasticity, scalability, availability, durability, reliability, economics, shared responsibility, SLI, SLO, and SLA.

## Module 2: Identity and core infrastructure

Users, groups, roles, policies, temporary credentials, federation, workload identity, virtual machines, images, instance sizing, autoscaling, storage types, lifecycle policies, relational databases, non-relational databases, replication, backup, consistency, and scaling.

## Module 3: Networking and application delivery

IP addresses, CIDR, TCP, UDP, DNS, routing, NAT, virtual networks, subnets, firewall rules, endpoints, peering, transit, hybrid connectivity, load balancing, TLS, content delivery networks, web application firewalls, APIs, and caching.

## Module 4: Containers and modern applications

Containers, images, registries, runtimes, Kubernetes clusters, pods, deployments, services, ingress, storage, health checks, serverless functions, event triggers, concurrency, queues, publish and subscribe, streams, retries, ordering, and idempotency.

## Module 5: Security, observability, and reliability

Defense in depth, zero trust, encryption, keys, secrets, certificates, vulnerability management, threat detection, metrics, logs, traces, alerts, incident response, fault tolerance, redundancy, RTO, RPO, backups, recovery, circuit breakers, timeouts, and graceful degradation.

## Module 6: DevOps, infrastructure, cost, and governance

Source control, CI/CD, artifacts, environments, feature flags, release strategies, GitOps, infrastructure as code, state, modules, drift, testing, pricing, data transfer, commitments, rightsizing, budgets, resource hierarchy, policies, landing zones, and compliance.

## Module 7: Data, analytics, AI, and migration

Data lakes, warehouses, lakehouses, ETL, ELT, batch processing, streaming, pipelines, catalogs, governance, model training, inference, generative AI, embeddings, vector search, retrieval-augmented generation, migration assessment, transfer, cutover, rollback, and modernization.

## Module 8: Architecture patterns and scenarios

Three-tier applications, microservices, event-driven systems, serverless systems, static websites, APIs, batch and streaming systems, SaaS, caching, queue-based load leveling, strangler migration, saga, CQRS, multi-region systems, secure landing zones, and integrated design scenarios.

## Module 9: Hands-on skills and job preparation

Reading architecture diagrams, provider consoles, command-line tools, log investigation, permission failures, network failures, application deployment, monitoring, backups, cost estimation, incident response, interview questions, whiteboard exercises, resumes, and portfolio projects.
